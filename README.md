# zhc-skills

Dr. Zhang's research workflow skills for Claude Code.

## What This Plugin Does

80 skills covering:
- **Cross-model debate** — structured Claude+Codex deliberation (codex-debate, codex-debug-pair, codex-experiment-critic, codex-paper-adversary, codex-skill-optimizer)
- **LLM compression** — SVD/MPO compression workflow (add-compression-method, add-model, compress, finetune)
- **Experiment management** — GPU job orchestration on A800 (run-experiment, run-gpu-experiment, run-pipeline, monitor-experiment, collect-results, experiment-bridge)
- **Paper writing** — full pipeline from plan to submission (paper-plan, paper-write, paper-compile, paper-presubmit-audit, shorten-latex, translate-zh-en)
- **Figure pipeline** — generation, audit, captioning (figure-pipeline, figure-designer, figure-spec, figure-audit, gen-figure-caption, gen-table-caption)
- **Research workflow** — ideation, literature, novelty check, weekly reports (research-lit, research-pipeline, novelty-check, weekly-report, vibe-research-workflow)
