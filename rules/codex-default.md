# Codex Default

- Always use `mcp__codex__codex` / `mcp__codex__codex-reply` (capture `threadId`, follow up incrementally).
- `reasoning_effort: xhigh` for everything (review, discussion, rescue) — no per-task differentiation.
- **Never** `Bash: codex exec ...` unless user explicitly says "use the CLI".
- `/codex-review`, `/codex:rescue` etc. are fine — they wrap MCP.
